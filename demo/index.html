SwiftConvert

Quiet upload matching for the browser. This demo accepts PNG on the main fixtures — with auto-convert on, pick sample.jpg or sample.heic and SwiftConvert converts before the page sees the file. Also try PDF→PNG, DOCX→text, and the 80 KB auto-compress fixture with sample-large.jpg.

How to verify

  1. Load the unpacked extension from the repo root (see README).
  2. Open this page via a local static server or file:// (extension needs host access).
  3. Pick demo/sample.jpg below. The result should show image/png.
  4. Optional: turn on “Preview before upload” in the popup and confirm the dialog.
